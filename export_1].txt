  3. Architektura orkiestratora

  Wykryte komponenty

  - Endpointy API (src/app/api/route.ts):
    - Obsługuje żądania HTTP (GET/POST) bez jasnej separacji logiki biznesowej.
    - Problem: Brak wzorca (np. MVC, Clean Architecture) — logika w endpointach.
  - Skrypty bash (.zscripts/mini-services-*.sh):
    - Uruchamiają mikroserwisy (np. mini-services-agent.sh), ale bez mechanizmu
  retry/circuit breaker.
    - Problem: Hardkodowane klucze API (OPENAI_API_KEY w skryptach).

  Wzorzec architektoniczny

  - Brak jednoznacznego wzorca:
    - Obecny kod sugeruje monolit z mikroserwisami (skrypty bash), ale bez
  synchronizacji stanu.
    - Rekomendacja: Wprowadzić Event-Driven Architecture (np. Kafka, RabbitMQ)
  lub Saga Pattern dla transakcji rozproszonych.

  Diagram przepływu (ASCII)

  [Frontend] → (HTTP) → [Next.js API (route.ts)]
      ↓
  [Prisma] → (SQL) → [PostgreSQL]
      ↓
  [Skrypty bash] → (CLI) → [Mikroserwisy]

  4. Architektura pamięci wektorowej

  Stan obecny

  - Brak implementacji:
    - Nie znaleziono modułów do embeddingów (np. vector_store/, embeddings/).
    - Brak bazy wektorowej (Chroma, Pinecone, FAISS).
  - Potencjalna integracja:
    - Skrypty bash (mini-services-agent.sh) mogą komunikować się z zewnętrznymi
  usługami AI (np. OpenAI Embeddings), ale nie przechowują danych lokalnie.

  Rekomendacje

  1. Dodanie lokalnej pamięci wektorowej:
    - Użyć FAISS lub LanceDB do przechowywania embeddingów.
    - Przykład integracji:
    // src/lib/vectorStore.ts
  import { FaissStore } from "@langchain/community/vectorstores/faiss";
  import { OpenAIEmbeddings } from "@langchain/openai";

  const embeddings = new OpenAIEmbeddings();
  const vectorStore = await FaissStore.fromTexts(
    ["Dokument 1", "Dokument 2"],
    [{ id: 1 }, { id: 2 }],
    embeddings
  );
  2. Strategia chunkowania:
    - Dzielić dokumenty na fragmenty po 512 tokenów z overlapem 10%.
    - Używać metadanych (np. source, timestamp) do filtrowania wyników.

  Przykład optymalizacji (CPU/I/O)

  Przed (blokujące zapytania):
  // src/app/api/route.ts
  export async function GET() {
    const users = await prisma.user.findMany(); // Blokuje event loop
    const posts = await prisma.post.findMany(); // Kolejne blokowanie
    return Response.json({ users, posts });
  }

  Po (async/await + batching):
  export async function GET() {
    const [users, posts] = await Promise.all([
      prisma.user.findMany(),
      prisma.post.findMany(),
    ]);
    return Response.json({ users, posts });
  }

  // src/lib/vectorStore.ts
  import { FaissStore } from "@langchain/community/vectorstores/faiss";
  import { OpenAIEmbeddings } from "@langchain/openai";
  import { RecursiveCharacterTextSplitter } from "langchain/text_splitter";

  export class VectorStore {
    private static instance: FaissStore;
    private static embeddings: OpenAIEmbeddings;

    private constructor() {}

    public static async getInstance() {
      if (!VectorStore.instance) {
        VectorStore.embeddings = new OpenAIEmbeddings({
          openAIApiKey: process.env.OPENAI_API_KEY,
        });
        VectorStore.instance = await FaissStore.load(
          "./vector_store",
          VectorStore.embeddings
        ).catch(() => new FaissStore(VectorStore.embeddings, {}));
      }
      return VectorStore.instance;
    }

    public static async addDocuments(documents: string[]) {
      const instance = await VectorStore.getInstance();
      const splitter = new RecursiveCharacterTextSplitter({
        chunkSize: 512,
        chunkOverlap: 50,
      });
      const chunks = await splitter.createDocuments(documents);
      await instance.addDocuments(chunks);
      await instance.save("./vector_store");
    }

    public static async similaritySearch(query: string, k: number = 3) {
      const instance = await VectorStore.getInstance();
      return instance.similaritySearch(query, k);
    }
  }

  export async function generateContent(prompt: string, context: string) {
    const systemPrompt = `Jesteś asystentem AI specjalizującym się w generowaniu
   spersonalizowanych treści.
    Użyj poniższego kontekstu, aby stworzyć odpowiedź: ${context}`;

    const response = await openai.chat.completions.create({
      model: "gpt-4o",
      messages: [
        { role: "system", content: systemPrompt },
        { role: "user", content: prompt },
      ],
    });

    return response.choices[0].message.content;
  }
